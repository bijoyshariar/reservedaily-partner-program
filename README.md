# ReserveDaily Partner Program

Affiliate partner referral programs for WooCommerce. Partner tagging through referral links, referral traffic and signup tracking, automatic category and product discounts, myCRED points multipliers with a partner welcome bonus, points expiry, a redemption cap, and commission tracking with manual settlement.

Built for reservedaily.com. Requires WooCommerce and myCRED (with myCRED Toolkit Pro for the points redemption cap). Uses WooCommerce legacy post storage, not HPOS.

The plugin lives in [`rd-partner-program/`](rd-partner-program/). See [`rd-partner-program/readme.txt`](rd-partner-program/readme.txt) for setup and post install steps, and [`rd-partner-program/changelog.txt`](rd-partner-program/changelog.txt) for the version history.

## Install

Copy the `rd-partner-program` folder into `wp-content/plugins` and activate it. Activation creates the database tables and default settings.
